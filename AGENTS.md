# AGENTS.md

This file provides guidance to AI coding assistants when working with code in this repository.

## What This Repo Is

`buddy-codecov` is an npm-distributed agent plugin. The package root at `packages/buddy-codecov/` is the plugin root and ships its manifests, public `skills/`, and bundled scripts.

## Commands

```
pnpm test
pnpm check
pnpm verify
```
